# `stratless init`

```
npx stratless init
```

## Claude Code deletes your history

Not "eventually". **After 30 days, per file** — so your archive rots from the back even in a project
you open every single day. The setting is `cleanupPeriodDays`, it defaults to 30, and almost nobody
knows it exists.

On the machine stratless was built on, everything before 9 June was **already gone**: months of
decisions, and the reasoning behind code that is still running in production, deleted on a timer
nobody had ever heard of.

## What `init` does

1. **Sets `cleanupPeriodDays` to 3650** in `~/.claude/settings.json`. The reaper stops.
2. **Copies every transcript** it can still find into `~/.stratless/archive/` — outside the
   cleanup's reach, permanently.

It takes two seconds, and it is the only part of stratless you cannot do later.

## Undo

Set `cleanupPeriodDays` back to `30` in `~/.claude/settings.json`, and delete
`~/.stratless/archive/`. That's all it touched.
