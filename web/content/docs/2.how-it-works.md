# How it works

**There's no trick.** That's not modesty, it's the whole design, and knowing it should make you trust the tool more, not less.

## The conversation was on your disk the whole time

Every assistant that can resume a chat has to store the chat. Yours are already on your disk (for Claude Code, as JSONL in `~/.claude/projects/`; see [Assistants](/docs/assistants) for each tool). Every exchange you've had, what you asked, what it said, and how you reacted, is already there.

**Nobody reads it.** The industry treats it as exhaust. Claude Code deletes it after 30 days.

stratless reads it.

## Read, discover, count, load

1. **Read.** It walks each session into moments: one thing you typed, paired with what the assistant was doing when you typed it. Whatever the code can settle for itself (which project you were in, whether you interrupted, which tools ran) is written down as fact, never guessed. The pile is cached, so each session is read once.

2. **Discover.** This is the part that makes it yours. stratless reads your pile and finds the recurring kinds of thing you actually do, minting one column for each, from your own history and nothing else. **Derived, not pre-matched:** there is no shipped list of categories to sort you into, because a list we wrote would be our model of a generic person, not a reading of you. A column has to appear across several different conversations to exist at all, so a one-off is never mistaken for a pattern.

3. **Count.** Each moment is checked against those columns, then counted: how many times, over what span, rising or fading, in bursts or steady. The division of labor is strict: your borrowed `claude` reads, checks, and picks a real line to illustrate each column; the code does every count. So no number in your profile is one the model made up, and each claim carries the exact evidence behind it.

4. **Write and load.** The profile is written from what the counts support, and only that. It leads with the things that cluster around moments that went wrong, so your assistant reads what to watch for first, then how you simply work. Then it lands in `~/.claude/HUMAN.md`, pointed at by a one-line import in your assistant's config, so your next session starts already knowing you. If the writer ever states a number that is not in the evidence, or returns anything that does not read like a profile, the build is refused and your old profile stays loaded.

A confident guess about you is the one failure that would make the whole tool worthless, so where a reaction carries no honest signal, it records nothing.

## It reads all of your history, not a recent slice

stratless builds its pile from your whole archive, so nothing you did is dropped for being old. The pile is deduped and cached, and that changes the economics: the first full build reads all of you and is the one real cost, quoted to you honestly before it runs. Every update after that pays only for what is new. A long history makes a richer profile without making each run slower, which is why `init` shows you the estimate and asks once, and why the after-session refresh is nearly free.

## Nothing you have to take on trust

This tool reads your entire conversation history, so the only honest design is one you can check. It runs on your machine and nothing leaves it: no account, no API key, no server, no telemetry. Reading your history and building your profile both happen locally, on the `claude` you already pay for. The one time it ever reaches the network on its own is the opt-in version check, a single request you can watch. And the whole thing is open source under MIT, so you do not have to believe any of this: you can read exactly what it does. *"trust me"* is the one thing we are not allowed to say.
