# How it works

**There's no trick.** That's not modesty, it's the whole design, and knowing it should make you trust the tool more, not less.

## The conversation was on your disk the whole time

Every assistant that can resume a chat has to store the chat. Yours are already on your disk (for Claude Code, as JSONL in `~/.claude/projects/`; see [Assistants](/docs/assistants) for each tool). Every exchange you've had, what you asked, what it said, and how you reacted, is already there.

**Nobody reads it.** The industry treats it as exhaust. Claude Code deletes it after 30 days.

stratless reads it.

## Read, judge, synthesize, load

1. **Read.** It walks each session into pairs: what the assistant said, and how you reacted.
2. **Judge.** It hands each pair to the `claude` you already have (`claude -p`, on your own plan) and asks one thing: did understanding transfer here, and about what? The signal is in your reaction. "ok, next" means it landed; "wait, what does this mean" means it didn't. One line back, cached forever, so each exchange is read exactly once.
3. **Synthesize.** It reads the whole pile of those judgments and writes the profile: a model of you, weighted to your current direction.
4. **Load.** It writes the profile to `~/.claude/HUMAN.md` and points your assistant's config at it (for Claude Code, a one-line import in `CLAUDE.md`), so your next session starts already knowing you.

If a reaction carries no honest signal, it records nothing. A confident guess about you is the one failure that would make the whole tool worthless.

## It reads your recent history, not all of it

A profile converges from your most recent exchanges (roughly the last 200). The older tail is diminishing returns, and, since people change direction, stale. So the first run is fast and every run stays cheap, whether you have 100 exchanges or 100,000.

## Why it's ~1,500 lines

Because you're going to read it.

This tool reads your entire conversation history. The first question any sensible person asks is *"is it phoning home?"* At about 1,500 lines you can audit the whole thing in an afternoon and satisfy yourself. At 50,000 nobody checks, and *"trust me"* is exactly the thing we're not allowed to say.

**The line count is the trust argument.**
