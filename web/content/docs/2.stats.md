# `stratless stats`

What your assistant has actually been doing, in the project you're standing in.

```
$ stratless stats

  Your assistant, in this project

    lines it wrote            189,592
    edits it made               6,348
    files it touched            1,073
    sessions                       80
    days                           36

    archive reaches back to 2026-06-09 — anything older was deleted by the cleanup.
```

You wrote none of that. You have never read most of it.

## Why the number is bigger than your repo

Those are lines the assistant **typed**, across every edit — including rewrites, replacements, and
experiments it later deleted. The repo those 189,592 lines produced is about 36,000 lines.

So it isn't just that you never read the code that survived. **You never saw the 150,000 lines of
decisions that were made, unmade, and remade along the way.**

## The date at the bottom matters

`archive reaches back to …` is the oldest transcript stratless can still find. Everything before it
was deleted by the 30-day cleanup, and it is not recoverable. Run `stratless init` and that line
stops moving.
