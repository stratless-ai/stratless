# Privacy

**stratless is a program that runs on your computer.** It is not a service. There is no server, no
account, no sign-up, and no API key. We do not receive your code, your conversations, or any
information about you — **because there is nowhere for it to go.**

## What it reads

Your coding assistant's conversation history, which is already on your disk
(`~/.claude/projects`), and the files in the repository you run it against.

It reads them. **It does not send them anywhere.**

## The one network call, and it isn't ours

The **"So what"** sentence is generated by **the assistant you already have installed**. stratless
shells out to it (`claude -p`) on your own subscription, and that request goes to your assistant's
provider exactly as it does when you use it normally.

**It never touches us.** We ship no model, hold no key, and run no proxy. No assistant installed?
stratless skips that line entirely and shows you the quoted history instead.

## What we collect

**Nothing.** No telemetry, no analytics, no crash reports, no usage counters, no phone-home of any
kind.

That is not a promise we're asking you to take on trust.
[The source is public and it's about 900 lines.](https://github.com/stratless-ai/stratless-cli)
Read it and confirm there is no network code in it.
