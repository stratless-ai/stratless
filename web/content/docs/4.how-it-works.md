# How it works

**There's no trick.** That's not modesty — it's the whole design, and knowing it should make you
trust the tool more, not less.

## The conversation was on your disk the whole time

Every assistant that can resume a chat has to store the chat. Claude Code keeps yours as JSONL in
`~/.claude/projects/`. Every edit it ever made to your code is in there — the exact text it wrote,
the file it wrote to, what you said just before, and what it said while doing it.

**Nobody reads it.** The industry treats it as exhaust. Claude Code deletes it after 30 days.

stratless reads it.

## Finding the decision — two witnesses, no guessing

The line you're asking about is still sitting in your file *right now*. So stratless doesn't
reconstruct history — it goes looking:

1. **Take the line plus a window of context** around it.
2. **Search every archived edit** for that text.
3. **Cross-check `git blame`**, which knows the commit that last *changed* that line.
4. If both witnesses agree → **`✓ matched`**. If they disagree → **`~ likely`**, and it tells you
   which one dissented and why.

`git blame` is the authority on *when* a line became what it is. If an edit merely rewrote the file
and reproduced your line unchanged, blame still points at the older commit — so stratless takes the
latest edit **at or before** the blame date. The alternative points you at the wrong conversation
with full confidence, which is the one thing it must never do.

## The only generated sentence

Everything above is **quoted**. Retrieval is deterministic — code matches strings, code slices
strings. It cannot invent a decision that isn't in your repo.

The one exception is the **"So what"** line — the plain-English consequence. That is written by the
assistant you already have (`claude -p`), on your own plan, grounded in your own diff. If it can't
state a consequence honestly, **it returns nothing and the line simply doesn't appear.**

## Why it's ~900 lines

Because you're going to read it.

This tool reads your entire conversation history. The first question any sensible person asks is
*"is it phoning home?"* At 900 lines you can audit the whole thing in an afternoon and satisfy
yourself. At 50,000 nobody checks, and *"trust me"* is exactly the thing we're not allowed to say.

**The line count is the trust argument.**
