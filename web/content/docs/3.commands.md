# Commands

```
stratless init       keep your history safe (add --auto for background refresh)
stratless profile    see the model of you (profile looks; update loads)
stratless report     the same picture, written for you to read
stratless update     judge what's new; rebuild + load the profile when due (--now: always)
stratless stop       turn it off, and unload the profile
stratless status     stratless's own state: on or off, and what it has cost
stratless stats      raw counts, instant, free, no tokens
```

## `init`

```
npx stratless init
```

Turns stratless on and stops the clock:

1. Stops Claude Code's 30-day reaper (sets `cleanupPeriodDays` to 3650 in `~/.claude/settings.json`) and copies every transcript it can still reach into `~/.stratless/archive/`, outside the cleanup's reach. Whatever has already aged out is gone. This is the only part you cannot do later.
2. Add `--auto` and it also installs the after-session refresh: what's new gets judged in the background when a session ends, and the profile rebuilds once enough has changed. Plain `init` arms nothing in the background; that is yours to turn on.

To undo: set `cleanupPeriodDays` back to `30` and delete `~/.stratless/archive/`. That is all it touched.

## `profile` and `report`

```
stratless profile    the AI's copy, what update loads into its context
stratless report     your copy, written for you to read
```

Both read your history and write a picture of how you work. `profile` is for your assistant; `report` is for you, where it talked over your head and where you went quiet. Neither changes anything: `profile` looks, and it ends by saying honestly whether a profile is loaded. Loading is `update`'s job. See [HUMAN.md](/docs/human-md).

## `update`

```
stratless update         judge what's new; rebuild + load the profile when it's due
stratless update --now   rebuild + load right now, no questions
```

Judges whatever is new since last time (each exchange once, then cached), and rebuilds the profile only when it's due: **25 new judgments** since the last build, a profile more than a week old with anything new in it, or no profile on disk yet. A gated skip is not an off state; the existing profile stays loaded, only the rebuild spend is skipped. This is what the after-session refresh runs for you.

Tune it: `STRATLESS_SYNTH_EVERY` changes the 25; `STRATLESS_SYNTH_MODEL` picks the model that writes the profile.

## `stop`

```
stratless stop
```

The off switch. Removes the after-session refresh and unloads the profile from your `CLAUDE.md`. Your `HUMAN.md` file is left as is; delete it yourself if you want it gone. Being able to shut it up is half of why you can trust it.

## `status`

```
$ stratless status

  stratless status

    after-session refresh   on
    profile loaded          yes  ~/.claude/HUMAN.md
    exchanges judged        1,412
    last refresh            2026-07-16
    spent so far            2.1M tokens across 1,412 reads  ≈ $2.06 at API rates, on your own claude
                            judging $0.91 (1,410) · profile builds $1.15 (2)
```

stratless's own state: whether the refresh is on, whether your profile is actually loaded, and what it has consumed of your borrowed `claude`. Tokens first, because a subscription spends quota, not dollars; the dollar figure is the API-equivalent, labelled as exactly that, split into judging and profile builds. Every line is read locally; `status` itself spends nothing. (`stats` below counts your *assistant's* activity in a project; `status` is about stratless itself.)

## `stats`

```
$ stratless stats

  Your assistant, in this project

    lines it wrote            189,592
    edits it made               6,348
    files it touched            1,073
    sessions                       80
    days                           36

    archive reaches back to 2026-06-09, anything older was deleted by the cleanup.
```

Raw counts, instant and free (no tokens spent). The `archive reaches back to` line is the oldest transcript stratless can still find. Run `init` and it stops moving.

## Flags

```
stratless --version    print the installed version (short: -v)
stratless --help       the command list
```
