# Honest limits

The whole product is one claim: **it does not lie.** So here is everything it can't do.

## Claude Code only, for now

Cursor, Windsurf, Cline and Codex all keep local conversation logs too — the architecture is *one
brain, thin readers* and those readers are next. Today, only Claude Code is supported.

## It can't explain code it never saw

- **You wrote the line?** It says **`yours`**. It won't invent an assistant decision to fill the gap.
- **The transcript was deleted before you ran `init`?** It says **`lost`**, and names the date it
  can't reach past.

## A generic line can't be traced

`}` and a bare import anchor nothing. stratless widens to the surrounding block — **and tells you it
did.** You will see a `note:` explaining every hedge, every partial match, and every disagreement
between the two witnesses.

## The "So what" sentence is generated

Retrieval is deterministic and cannot hallucinate. The plain-English consequence is written by an
LLM, grounded in your diff, and instructed to return nothing rather than guess. **It is still a
generated sentence.** Read the receipt above it — that part is quoted, and it's the part you can
check.

## It doesn't stop your AI from doing this

stratless tells you what got decided. It does not yet stop your assistant from deciding things
badly, silently, or in language you don't speak. That's the next thing.

## And it's n = 1

stratless was built by one person, from one person's transcripts, over five weeks. The problem is
real *for him* with total certainty and for everyone else with none. If you run it and the numbers
look nothing like his, **that is the most useful thing you could possibly tell us** —
[open an issue](https://github.com/stratless-ai/stratless-cli/issues).
