# Honest limits

The whole product is one claim: **it does not lie.** So here is everything it can't do.

## One assistant today

Only Claude Code is supported right now. The rest roll out one batch at a time, the CLIs next and the GUIs later. See [Assistants](/docs/assistants) for the full list and where yours stands.

## It reads your recent history, not all of it

A profile converges from your most recent exchanges (roughly the last 200), so that is what it reads. Ancient history is diminishing returns and, since people change direction, often stale. If your older work matters and isn't showing up, that is the reason.

## The profile is generated, and a model can be wrong

A profile is not a receipt. It is synthesized by an LLM from real per-exchange judgments, and it is told to say less rather than invent. But it is still a model of a person, reasoned from evidence. It can be wrong, and it can echo itself: if it decides something about you and the assistant then leans into it, your reactions can quietly confirm a read that was off. Read your `profile --read`; if it doesn't sound like you, that is the most useful thing you can tell us.

## It fits the model, it doesn't fix it

stratless doesn't make your assistant smarter. It gives the assistant a model of you, so it stops explaining at the wrong altitude. That is the whole job, and it is smaller than "AI that gets you."

## And it's n = 1

stratless was built by one person, from one person's transcripts. The problem is real *for him* with total certainty, and for everyone else with none. If you run it and the profile looks nothing like you, [open an issue](https://github.com/stratless-ai/stratless/issues). That is the most useful thing you could possibly tell us.
