# `stratless why`

Point at any line of your code. Get the decision that made it.

```
stratless why <file>:<line>
```

## What you get

```
$ stratless why apps/api/src/lib/authState.ts:174

  const payload = { p: 'console', acct: opts.acct, exp: Date.now() + …

  ✓ matched  100% · written 2026-07-09 · session 2d1ac2b8

  You said   "lets plan it out properly first and enter plan mode for this…"
  It said    "Now I have the full GitHub flow. My plan for Layer 2: switch the sessio…"

  So what    Console sessions expire after 30 minutes with no refresh, so anyone
             testing the console during launch gets logged out mid-session and
             has to re-authenticate.

  git: 22a504fa 2026-07-09 — feat(api): accounts + Google login
```

**Nobody decided 30 minutes.** It got picked on a Thursday while you were thinking about something
else. That's the whole product.

## The four answers — three of them are refusals

| | |
|---|---|
| **✓ matched** | Found the decision, and `git blame` agrees. Two independent witnesses. |
| **~ likely** | Found something, but the witnesses disagree — **and it tells you exactly how.** A lead, not a fact. |
| **yours** | No assistant edit contains this line. **You wrote it.** |
| **lost** | The conversation that explains this line was **deleted** by the 30-day cleanup, before you ran `init`. |

It would rather say nothing than guess. A confident answer about a line it didn't actually match is
the one failure that would make the whole tool worthless.

## When it can't be sure

A short, generic line (`}`, a bare import) anchors nothing. stratless widens to the surrounding
block **and says that it did**. You'll see a `note:` line explaining every hedge.
